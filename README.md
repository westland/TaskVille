## 🌟 What is TaskVille?

**TaskVille** recreates and expands upon the autonomous multi-agent virtual office paradigm for solopreneurs, growth teams, and operators. Instead of manually prompting chatbots one-by-one or building complex automation pipelines, TaskVille provides a gamified, interactive **2.5D Isometric Virtual Office** where autonomous AI workers collaborate, level up, chat at the watercooler, and execute complex business operations on complete autopilot.

---

## 🚀 Key Features

- **🎮 2.5D Isometric Interactive Canvas:** A cyber-lounge virtual floor with depth-sorted agent avatars, energetic circuit paths, room status hotspots, and live floating speech bubbles.
- **⚡ Autonomous Swarm Orchestration:** Decompose high-level strategic goals into specialized multi-agent workstreams across Executive, Research, Copywriting, Visual Design, Growth, and API integrations.
- **⏱️ Autopilot & Recurring Schedules:** Pre-engineered cron routines for morning intelligence digests, daily social drops, competitor monitoring, and inbound lead qualification.
- **🔌 250+ SaaS & Tool Integrations:** Connectors for Gmail, Slack, HubSpot, Notion, X/Twitter, Stripe, GitHub, Shopify, and custom webhooks.
- **🤖 Live Google Gemini AI Integration:** Uses Google Gemini Generative AI for real-time dynamic mission planning and bespoke direct agent directives.
- **🔊 Procedural Web Audio Engine:** Retro-futuristic synthesizer audio FX for task completions, mechanical typing, delegation whooshes, and coffee lounge brews without external media files.
- **📦 Executive Deliverables Vault:** Interactive multi-tab deliverable viewer with one-click clipboard copying and Markdown file downloads.

## 🛠️ Quickstart

### Prerequisites
- [Node.js](https://nodejs.org/) v18+
- [Git](https://git-scm.com/)

### Local Development
```bash
# Clone the repository
git clone https://github.com/westland/TaskVille.git
cd TaskVille

# Install dependencies
npm install

# Setup environment
cp .env.example .env

# Launch dev server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🐳 Docker & Server Deployment (Hetzner CX23)

TaskVille is pre-configured with a multi-stage Docker build and Nginx production server.

```bash
# Run with Docker Compose
docker compose up -d --build
```

### Automated Hetzner Deployment:
Run the automated deployment script on your Ubuntu server:
```bash
bash deploy-hetzner.sh
```
